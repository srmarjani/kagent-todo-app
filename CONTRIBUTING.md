# Contributing to kagent-todo-app

Thanks for your interest in the project!

## Running the app locally

This repository currently contains only a README, so there is no runnable app yet. Once the app code lands, follow these general steps:

1. Clone the repository:
   ```bash
   git clone https://github.com/srmarjani/kagent-todo-app.git
   cd kagent-todo-app
   ```
2. Install the dependencies listed in the project's manifest (for example `package.json`, `requirements.txt`, or `go.mod`).
3. Start the app using the run command documented in the README. If none is documented yet, please add one in your pull request.

## Opening an issue

1. Check the [existing issues](https://github.com/srmarjani/kagent-todo-app/issues) to avoid duplicates.
2. Click **New issue** and give it a clear, specific title.
3. Describe what you expected, what happened, and the steps to reproduce it. Include your environment (OS, runtime version) when relevant.
4. For feature ideas, explain the problem you want solved, not only the solution.

## Submitting changes

1. Create a branch from `master`.
2. Make your change and keep commits focused.
3. Open a pull request that describes what changed and why.
